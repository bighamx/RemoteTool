# Web 与 Android 功能对齐

基于上游 master 的 c130e97 整合，保留空间管理、Agent 安装配置、会话权限切换及审批逻辑。

## 页面与导航

- 手机端使用系统、远程、Codex、Hermes、更多五项导航；会话列表和聊天分别显示，保留桌面工作台。
- 点击后立即展示目标页的加载状态，HTML/样式/脚本异步加载；失败留在目标页重试，旧请求不能覆盖新路由。
- 顶部恢复官方额度、上下文 token/上限/百分比、提供方和模型信息；消息正文 14px，紧凑气泡与明确的操作入口。
- 手机输入栏保留附件、工具、发送/停止；弹窗采用底部面板；文件和进程表格按卡片展示，文件排序及操作保留。
- Enter 在手机上换行，Ctrl/Command+Enter 发送；输入法组合期间不发送。返回列表/浏览器前后退保留草稿。

## 键盘兼容

使用窗口、文档和 visualViewport 的较小高度，监听 resize/scroll 与键盘边界，聚焦时补充低频尺寸检测。保留浏览器原生键盘避让。

部分手机浏览器完全不报告键盘尺寸。触屏聊天框聚焦 500ms 后仍无有效尺寸时，临时将输入栏排在标题下方，点击“完成”恢复；不猜测键盘高度。已观察到有效尺寸的正常输入过程不触发该兼容模式。

“更多 → 键盘诊断”仅在本地保存最近 40 条尺寸与浏览器信息，可手动复制；不记录消息、身份或凭据，不自动上传。真实手机兼容性仍需设备验证。

## 会话加载与状态

- 后台发现新增会话和改名，保留当前选择；支持按 ID 搜索及跨首屏直达链接。
- 先显示历史，再加载较慢的上下文、运行状态等辅助信息；模型目录按需加载，隐藏模块暂停轮询。
- 内存和 sessionStorage 历史快照按设备、已登录用户、Agent/Profile 隔离，30 分钟过期；最多 20 条、总计约 2 MiB，单条约 512 KiB/最近 80 条消息。
- 缓存显示同步状态；不保存运行状态、审批或发送回执，不用缓存确认投递；新历史（包括空结果）覆盖快照，删除/回退使缓存失效。
- 会话级模型目录、官方别名、聚合标识、自定义模型与 Hermes 推理关闭状态保持一致；请求竞态不能串会话。
- 定时消息和队列保留目标会话、请求键与未知回执，避免导航或重试造成重复投递。

## Cloudflare

新增 Web 账户、DNS、R2、D1 与 Tunnels 页面，复用服务端加密凭据存储。支持只读 DNS 元数据、R2 游标与目录、参数化 SQL，以及保存隧道路由时保留高级字段和兜底规则。断开连接使用 connector ID。浏览器不持久化密钥，Android 配置不自动迁移。

## 可选的新会话完全访问

服务端配置 `Codex:NewSessionFullAccess=true`（环境变量 `Codex__NewSessionFullAccess=true`）时，远程新建会话使用 `danger-full-access` / `approvalPolicy=never`，通过上游会话权限存储记录为 `full`。恢复会话读取当前模式，已有会话不批量迁移；用户之后可继续通过上游权限面板切换模式。

默认 false，不自动扩大其他部署的权限。该设置是服务端的新会话默认值，不自动追踪桌面 UI 默认值。Bridge 协议版本提升为 36，使用既有交接流程。

- Codex / Hermes 新建会话与 Android `PhoneSessionOptions` 对齐，提供关闭、注入说明、启用工具及高级操作确认。默认关闭手机能力与高级操作；工具模式要求在线设备，说明模式离线时由已有服务端跳过。旧服务 404 显式提示更新，普通创建仍可用。
- 处理设备列表竞态、离线设备不自动换绑、重复点击、创建结果未知及离开页面后的迟到响应。MCP 令牌只在创建后当前页面内显示，不写 localStorage/sessionStorage；关闭配置或离开页面清除，撤销需要明确确认。
- 修复文件排序菜单被同一次点击关闭的问题；菜单重建后的点击仍保持打开，补齐手机排序/文件操作底部面板样式。
- 将旧的思考过程用例与当前 Android/Web 的“工具期间合并、真实旁白后新分段、终态淡出删除”语义对齐，不修改思考产品逻辑；浏览器用例使用上游当前的新建按钮及文件操作入口。

## 2026-11-10：Material 3 界面与远程访问加载

- 新增 `wwwroot/css/m3.css`，按 Android 主 App 的 Material 3 配色和组件样式覆盖 Web：药丸按钮、填充卡片、导航栏指示器、侧栏与顶栏、系统页操作按钮、会话卡片、聊天气泡与输入栏、底部面板，深浅主题均覆盖。规则全部限定在 `<html class="ui-m3">` 下，移除该 class 即恢复原样式；不改动脚本逻辑与 DOM 结构。
- 手机聊天页：额度与上下文行去掉固定行高；气泡时间内联到最后一行末尾（以代码块、表格、附件等结尾时保留独立行）；“操作”按钮保留并缩为“⋯”，可访问名称与文字不变；工具摘要与时间同行。手机消息正文仍为 14px。
- 压缩：.NET 8 以 `text/javascript` 提供 `.js`，原 MIME 列表未包含，脚本此前未压缩；补充 `text/javascript`、`image/svg+xml`、`application/manifest+json`，Brotli 级别改为 Optimal（质量 4）。
- 缓存：带 `?v=` 的静态资源返回 `public, max-age=31536000, immutable`，`/icons/`、`/mobile/` 为一天，其余 `no-cache`（以 ETag 重新验证）。`data-build` 由每次渲染的 `DateTime.UtcNow.Ticks` 改为启动时按 wwwroot 文件路径、大小、修改时间计算的 `ServerBuild.AssetVersion`，按需加载的脚本与样式不再在每次刷新时重新下载。
- 路由：首屏显示后在空闲时预取 Codex、远程、Hermes 的页面 HTML，并以 `<link rel=prefetch>` 预热其样式与脚本；不提前挂载或执行。预取结果仅使用一次，登录失效或失败时回到原有加载路径；`Save-Data` 时不预取。

验证：22 项 Node 前端检查、`web-parity-browser` 与 `phone-tools-browser` 两组 Playwright 隔离浏览器回归、Release 构建。浏览器模拟 150ms 延迟、约 2Mbps 下，冷启动 9.3s/2083KB → 约 4.8s/721KB，刷新 1.76s/308KB → 约 0.3s/55KB，首次切换 Codex 1.8s → 0.5s。在一台 macOS 服务端经 Cloudflare Tunnel 部署并用 Android 手机浏览器访问；未在 iOS、Windows 服务端上验证。

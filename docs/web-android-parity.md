# Web 与 Android 功能对齐

基于上游 master 的 c130e97 整合，保留空间管理、Agent 安装配置、会话权限切换及审批逻辑。

## 页面与导航

- 手机端使用系统、远程、Codex、Hermes、更多五项导航；会话列表和聊天分别显示，保留桌面工作台。
- 点击后立即展示目标页的加载状态，HTML/样式/脚本异步加载；失败留在目标页重试，旧请求不能覆盖新路由。
- 顶部恢复官方额度、上下文 token/上限/百分比、提供方和模型信息；消息正文 14px，紧凑气泡与明确的操作入口。
- 手机输入栏保留附件、工具、发送/停止；弹窗采用底部面板；文件和进程表格按卡片展示，文件排序及操作保留。
- Enter 在手机上换行，Ctrl/Command+Enter 发送；输入法组合期间不发送。返回列表/浏览器前后退保留草稿。

## 键盘兼容

使用窗口、文档和 visualViewport 的较小高度，监听 resize/scroll 与键盘边界，聚焦时补充低频尺寸检测。保留浏览器原生键盘避让。

部分手机浏览器完全不报告键盘尺寸。触屏聊天框聚焦 500ms 后仍无有效尺寸时，临时将输入栏排在标题下方，点击“完成”恢复；不猜测键盘高度。已观察到有效尺寸的正常输入过程不触发该兼容模式。

“更多 → 键盘诊断”仅在本地保存最近 40 条尺寸与浏览器信息，可手动复制；不记录消息、身份或凭据，不自动上传。真实手机兼容性仍需设备验证。

## 会话加载与状态

- 后台发现新增会话和改名，保留当前选择；支持按 ID 搜索及跨首屏直达链接。
- 先显示历史，再加载较慢的上下文、运行状态等辅助信息；模型目录按需加载，隐藏模块暂停轮询。
- 内存和 sessionStorage 历史快照按设备、已登录用户、Agent/Profile 隔离，30 分钟过期；最多 20 条、总计约 2 MiB，单条约 512 KiB/最近 80 条消息。
- 缓存显示同步状态；不保存运行状态、审批或发送回执，不用缓存确认投递；新历史（包括空结果）覆盖快照，删除/回退使缓存失效。
- 会话级模型目录、官方别名、聚合标识、自定义模型与 Hermes 推理关闭状态保持一致；请求竞态不能串会话。
- 定时消息和队列保留目标会话、请求键与未知回执，避免导航或重试造成重复投递。

## Cloudflare

新增 Web 账户、DNS、R2、D1 与 Tunnels 页面，复用服务端加密凭据存储。支持只读 DNS 元数据、R2 游标与目录、参数化 SQL，以及保存隧道路由时保留高级字段和兜底规则。断开连接使用 connector ID。浏览器不持久化密钥，Android 配置不自动迁移。

## 可选的新会话完全访问

服务端配置 `Codex:NewSessionFullAccess=true`（环境变量 `Codex__NewSessionFullAccess=true`）时，远程新建会话使用 `danger-full-access` / `approvalPolicy=never`，通过上游会话权限存储记录为 `full`。恢复会话读取当前模式，已有会话不批量迁移；用户之后可继续通过上游权限面板切换模式。

默认 false，不自动扩大其他部署的权限。该设置是服务端的新会话默认值，不自动追踪桌面 UI 默认值。Bridge 协议版本提升为 36，使用既有交接流程。

## 验证

- WebApplication 编译与 Razor 检查。
- 前端 Node 回归：消息、模型、发现、缓存、回执、定时消息和 Cloudflare 状态。
- AgentContracts：权限的新建、恢复、模式切换、未标记会话隔离，以及上游既有契约。
- Cloudflare 模拟契约与 Playwright 隔离浏览器：路由阻塞/快速切换/重试、桌面与手机、余量、模型、缓存、工具面板、键盘尺寸/平移/无事件/不报告尺寸、Cloudflare 页面。

测试使用隔离目录和模拟接口，不执行真实 Cloudflare 写入或真实模型推理。浏览器模拟通过不等同于所有手机真机通过。

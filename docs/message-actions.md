# 手机消息气泡操作

- 单击气泡文字或空白边距，弹出复制／分叉菜单；自己发送的消息还提供编辑。长按文字继续使用原生文本选择，链接和附件保留原来的打开行为。
- 菜单在抬起手指后才打开；超过系统滑动阈值、长按、手势取消或多指操作均不算单击。
- 复制保留完整消息文字，不复制消息时间、发送状态，也不使用旁白显示截断后的文本。
- Codex 分叉使用当前本机协议的 `thread/fork(lastTurnId)`，保留选定消息所在的**完整轮次**及之前历史。菜单显示这一范围。消息所在轮次执行中时不能分叉。
- Hermes 分叉使用原生 SessionDB 的建会话及消息复制方法，保留选定消息及之前的活动历史，继承模型配置和目录，不结束原会话。已被压缩归档且不在活动上下文中的旧消息，当前接口不能直接作为撤回／分叉目标。
- 编辑只针对已保存的用户消息；先在对话框修改文字、保留或移除原附件，点击「撤回并重发」才撤回原消息及后续对话并发送新内容。运行中、发送结果未核对时不能编辑。Codex 插话消息不能单独撤回，因为原生撤回按整轮执行。
- Codex 编辑使用本机协议的 `thread/revert(beforeTurnId)`；Hermes 使用原生 `rewind_to_message` 的软撤回和写入保护，区分普通消息与压缩复合消息，校验活动记录和最新用户消息，避免误删并发新内容。
- 编辑会保留草稿；撤回响应不确定时不自动重发。撤回成功但历史读取失败时提示原消息已撤回、尚未重发，并把编辑内容留在输入框。
- 分叉继承已绑定附件的索引和预览链接，共用原文件，避免复制大文件。后续编辑分叉消息时仍可重新发送这些附件。
- 操作不会撤销之前执行的文件修改或程序操作。

需要同时更新 App 和 Web 服务端。Codex bridge 状态版本升至 11，防止服务端更新后继续复用缺少新接口的旧 bridge。旧服务端的气泡仍可复制，分叉／编辑暂不可用。

验证：Android 手势单元测试；Hermes 适配单元测试与隔离原生数据库测试；Codex 隔离 Home + 本地模拟推理接口的原生分叉／撤回／重发测试；附件索引、嵌套分叉与重新发送检查。未连接手机做触摸实测。

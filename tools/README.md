# 共用与 App 工具

- `PhoneTools/`：手机直连/服务端转发 HTTP MCP 客户端、CLI、Hermes 插件与技能，支持独立于 Web 使用。
- `android_ci.py`、`check_android_editions.py`：Android 构建与版本校验。
- `Publish-AppUpdate.ps1`：Android APK 与 App 更新清单发布。

Web 专属工具已归到 [WebApplication/Tools](../WebApplication/Tools/README.md)。服务端发行与开发目录重编译见 [服务端更新](../WebApplication/SERVER-UPDATES.md)。
